## 20260605美股大跌的原因调查
1. 股市中的资金被抽走：SpaceX即将上市，大家提前卖出，准备拿钱买SpaceX。
2. 加息恐慌：原本大家觉得比起加息，政府更应该先解决低就业率的问题，但20260605新的就业数据显示就业率远超预期，再加上最近油价上涨导致通胀增加，大家认为加息的概率增加了。
3. AI表现不及预期：现在大家对AI的狂热程度很高，于是人们的预期是AI发展得必须特别好，但鉴于像Google这样的龙头AI企业最近开始面向public募资，大家觉得现在AI烧的钱还是太多了，收益却遥遥无期
